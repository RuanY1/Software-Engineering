## 项目简介
本项目是《软件工程》课程的结对编程作业，采用 HTML+CSS+JavaScript 开发。

## 核心功能
1. 书签联系人：支持收藏重要联系人，并在列表置顶显示。
2. 多种联系方式：一个联系人支持添加多个电话、邮箱等。
3. Excel 导入导出：支持数据导出为 Excel 表格，及读取 Excel 导入数据。
